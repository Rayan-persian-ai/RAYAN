# رایان در برابر chatgpt.com — فهرست هم‌ترازی (ChatGPT parity)

به‌روزرسانی: ۲۰۲۶-۱۱-۲۶ (شاخهٔ `phase-4-parity`). قید ثابت: هزینهٔ صفر (فقط لایهٔ رایگان Cloudflare و سرویس‌های رایگان واقعی)، فارسی RTL، بدون دکمهٔ نمایشی/غیرفعال.

راهنما: ✅ پیاده‌سازی و آزمون زنده شد · 🟡 بخشی · ⏳ برنامه‌ریزی‌شده (به ترتیب اولویت)

| # | امکان ChatGPT | وضعیت | پیاده‌سازی در رایان / برنامه |
|---|---|---|---|
| 1 | نوار کناری تاریخچه + جست‌وجو | ✅ | D1 + `GET /api/conversations?q=` (عنوان و متن پیام‌ها) |
| 2 | تغییر نام / حذف گفت‌وگو / حذف همه | ✅ | `PATCH/DELETE /api/conversations/:id`، `DELETE /api/conversations` |
| 3 | سنجاق کردن (pin) گفت‌وگو | ⏳ اولویت ۱ | ستون `pinned_at` + بخش «سنجاق‌شده‌ها» بالای فهرست |
| 4 | پاسخ زنده با توقف | ✅ | SSE از Worker، `ReadableStream.cancel` → ذخیرهٔ پاسخ نیمه‌کاره |
| 5 | پاسخ دوباره | ✅ | `POST /regenerate` |
| 6 | ویرایش پیام و ارسال دوباره | ✅ | `POST /truncate` + ارسال دوباره (شاخه‌بندی نسخه‌ها ⏳) |
| 7 | Markdown + برجسته‌سازی کد + کپی | ✅ | `markdown.ts` (ایمن) + `highlight()` + کپی/دانلود/zip |
| 8 | انتخاب مدل | 🟡 | الان: «☁️ رایان (سرور)» یا «📴 آفلاین در مرورگر». ⏳ اولویت ۲: فهرست مدل‌های رایگان Workers AI (سریع/قوی) با سقف هزینهٔ جدا |
| 9 | بارگذاری فایل | ⏳ اولویت ۳ | متن/CSV/MD/PDF متنی در مرورگر استخراج و به زمینه افزوده شود (بدون ذخیرهٔ فایل؛ R2 رایگان فقط در صورت نیاز) |
| 10 | بارگذاری تصویر (بینایی) | ⏳ اولویت ۳ | Llama 4 Scout روی Workers AI چندوجهی است؛ تصویر کوچک‌شده در مرورگر → base64 → همان زنجیره |
| 11 | ساخت تصویر | ✅ | Pollinations flux (رایگان، بدون کلید) با ترجمهٔ خودکار فارسی |
| 12 | صدا: ورودی و خواندن پاسخ | ✅ | Web Speech API (fa-IR) + speechSynthesis |
| 13 | دستورهای سفارشی (custom instructions) | ✅ | تنظیمات → شخصی‌سازی (اسم، سبک، دربارهٔ من) در system prompt |
| 14 | حافظه (memory) | ⏳ اولویت ۴ | جدول `memories` (کاربر می‌بیند/حذف می‌کند)، پیشنهاد «به خاطر بسپار» با تأیید کاربر |
| 15 | پروژه‌ها/پوشه‌ها | ⏳ اولویت ۵ | جدول `projects` + `conversations.project_id` + دستور اختصاصی هر پروژه |
| 16 | پیوند اشتراکی | ✅ | `#/share/<id>`، قابل لغو |
| 17 | ایجنت‌ها / GPTهای سفارشی | ⏳ اولویت ۶ (دستهٔ ۳) | ایجنت‌های مدیریت‌شده روی cortex/autopilot: نوشتن محتوا، خلاصه، پیش‌نویس و ارسال ایمیل با صف تأیید، کد تأیید؛ لاگ اجرا |
| 18 | جست‌وجوی وب با منبع | ✅ | ویکی‌پدیای فارسی + گنجور برای شعر |
| 19 | خروجی فایل (Word/PDF/zip) و پیش‌نمایش کد | ✅ | `docx.ts`، `/print`، `/preview` (sandbox) |
| 20 | تیره/روشن | ✅ | روشن / تیره / مطابق سیستم |
| 21 | واکنش‌گرا برای موبایل | ✅ | نوار کناری کشویی با پس‌زمینهٔ تیره، آزمون در ۳۹۰×۸۴۴ |
| 22 | فارسی RTL | ✅ | سراسر رابط RTL، `dir="auto"` برای متن مخلوط |
| 23 | ورود با گوگل و کد ایمیل | ⏳ دستهٔ ۲ | OAuth 2.0 + PKCE سمت Worker، کد ۶ رقمی (هش‌شده، ۱۰ دقیقه) با Gmail API |
| 24 | کار آفلاین | ✅ (فراتر از ChatGPT) | Gemma 3 1B در مرورگر با wllama |
| 25 | میان‌برهای صفحه‌کلید | ✅ | `?` فهرست را نشان می‌دهد |

ترتیب دسته‌های بعدی: ۲) ورود با گوگل + کد ایمیل + ارسال با Gmail API؛ ۳) ایجنت‌ها با صف تأیید؛ سپس pin، انتخاب مدل، بارگذاری فایل/تصویر، حافظه، پروژه‌ها.
